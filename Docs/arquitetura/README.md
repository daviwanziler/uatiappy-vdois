# Arquitetura do UatiAppy

Esta pasta contém os documentos e diagramas relacionados à arquitetura de software do UatiAppy.

## Diagrama de Arquitetura

O diagrama apresenta a organização dos componentes do sistema, suas responsabilidades e as relações entre a aplicação, os serviços de backend, o banco de dados e a infraestrutura de desenvolvimento e implantação.

> **Atenção:** a stack tecnológica foi detalhada em documento complementar após a criação do diagrama. A compatibilidade entre este registro e o PDF de arquitetura deve ser conferida na revisão da documentação. Caso o diagrama apresente tecnologias diferentes, ele deverá ser atualizado após validação da equipe e do orientador.

## Stack tecnológica

A proposta tecnológica atual para o MVP mobile está registrada em [Decisões Tecnológicas](./decisoes-tecnologicas.md).

## Documentação complementar

Os documentos desta pasta devem manter coerência com os requisitos funcionais, não funcionais e o escopo do MVP.
